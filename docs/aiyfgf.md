# 枫叶指令宏 - 官方语法设计文档

**适用对象**：AI解析器、脚本编辑器、语言实现者

## 1. 概述与执行模型

枫叶指令宏是一种**逐行解释、无AST、基于块关键字扫描**的脚本语言。其设计目标是提供直观的自动化指令集合，支持条件判断、循环、模块化、定时任务以及丰富的屏幕操作（识图、找色、键鼠模拟等）。

### 1.1 执行模型核心规则

- 脚本由换行符（`\n`）分割为独立行，回车符（`\r`）被忽略。
- 每一行的基本结构为：`指令头\参数段`。
- 参数段内部子参数使用英文逗号 `,` 分隔。
- 注释标记为分号 `;`，从 `;` 开始到行尾的内容全部丢弃（不解析）。
- 空白行（去除两端空白后为空）直接跳过，不产生任何效果。
- 所有变量均为**全局变量**，不存在块级作用域。变量存储于全局变量池中。
- 变量取值前缀为 `@`，支持普通变量、数组索引、拼接表达式。
- 条件判断不使用传统布尔表达式，而是采用**专用判断语法**，由条件类型与参数组成。多个条件可通过逻辑连接词 `\与\`、`\或\` 组合。
- 块结构（`如果`、`循环`、`模块定义`）依赖于起始关键字与结束关键字的配对，通过手动扫描多行实现嵌套支持。

### 1.2 执行流程

1. 读取脚本文本，按行分割。
2. 依次处理每一行：
   - 去除行内注释（`;` 之后部分）。
   - 去除首尾空白，若为空行则跳过。
   - 解析指令头和参数段。
   - 执行对应指令或进入块处理逻辑。
3. 遇到块起始指令时，递归或循环扫描后续行直至找到匹配的结束关键字，并执行块体。
4. 脚本可被外部中断（如用户停止），此时立即终止执行。

### 1.3 指令分类

枫叶语言中的指令分为两类：

| 指令类型 | 说明 | 示例 |
|---------|------|------|
| **执行指令** | 可独立执行，完成具体操作 | `变量\等级,10`、`鼠标移动\100,200`、`延迟\500,800` |
| **条件指令** | **只能**用于 `如果\` 后面，不能独立执行 | `识图\...`、`识图CV\...`、`坐标找色\...`、`范围找色\...`、`比较\...` |

 **重要**：条件指令（`识图`、`识图CV`、`坐标找色`、`范围找色`、`比较`）**不能单独写在一行**，必须紧跟在 `如果\` 后面作为条件子句。否则解析器会报告“未知指令”错误。


## 2. 词法规范

### 2.1 令牌（Token）

脚本由以下基本令牌组成：

| 令牌类型       | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| 指令头         | 以字母或汉字开头的标识符，例如 `变量`、`循环`、`识图`。      |
| 参数           | 指令头之后的参数段，由逗号分隔的多个参数项。                 |
| 分隔符         | 反斜杠 `\` 用于分隔指令头与参数段，也用于分隔逻辑连接词。   |
| 逗号           | `,` 用于分隔参数段内的子参数。                               |
| 注释符         | `;` 标记单行注释，从该符号到行尾均被忽略。                   |
| 换行符         | `\n` 作为行结束符。                                          |
| 变量前缀       | `@` 用于引用变量、数组元素或拼接表达式。                     |
| 字符串         | 参数中直接书写的文本，无需引号包裹。                         |
| 数字           | 整数或浮点数（如 `10`、`3.14`）。                            |
| 十六进制颜色   | 以 `0x` 开头的六位十六进制数，如 `0xFF0000`。                |
| 尖括号标记     | 以 `<` 开头、`>` 结尾的标记名，用于引用识图模板或图片名。   |

### 2.2 分隔符优先级

- 行内首先识别注释 `;`，注释之后的内容全部丢弃。
- 然后识别指令分隔符 `\`，将行分为指令头和参数段。
- 参数段内再以 `,` 分割子参数。
- 变量引用 `@` 可在参数任何位置出现，会被递归解析。

### 2.3 空白字符处理

- 行首和行尾的空白字符（空格、制表符）被忽略。
- 参数内部的空白字符通常会被保留，但解析器会在必要时进行修剪（如去除参数两端的空格）。
- 空行直接跳过。

### 2.4 注释

- 单行注释：`;` 之后的所有字符均视为注释，不被执行。
- 不支持多行注释。

### 2.5 换行规则

- 每行必须以 `\n` 结尾（`\r` 被过滤）。
- 行结束即指令结束，不存在隐式续行。
- 块结构通过关键字配对跨越多个物理行。


## 3. 变量系统

### 3.1 变量定义与赋值

使用 `变量\变量名,值` 指令创建或修改变量。

```
变量\玩家等级, 85
变量\是否激活, 1
变量\名称, 张三
```

- 变量名由字母、数字、下划线、汉字组成，不能以数字开头。
- 值可以是数字、字符串、布尔值（1/0）或其它指令的结果。
- 所有变量存储于全局变量池中，脚本任意位置均可访问。

### 3.2 变量取值语法

使用前缀 `@` 引用变量值：

```
弹窗提示\当前等级是 @玩家等级
```

#### 3.2.1 数组索引访问

若变量存储的是数组，可通过 `@变量名[索引]` 访问元素，**索引从 1 开始**。

```
-数组元素列表使用竖线 `|` 分隔，支持中文竖线 `丨` 作为替代。
数组\创建,英雄列表, 亚瑟|后羿|妲己
弹窗提示\第一个英雄是 @英雄列表[1]
```

索引可以是数字字面量或变量：

```
变量\序号, 2
弹窗提示\第二个英雄是 @英雄列表[@序号]
```

#### 3.2.2 拼接表达式 `@(xxx)`

当变量名需要动态拼接时，使用 `@(拼接内容)` 语法。拼接内容由字面量、变量引用通过 `.` 连接而成，解析时会先计算所有变量引用，再拼接成最终变量名。

**示例**：

```
变量\A1, 111
变量\数字, 1
弹窗提示\@(A.@数字)          ; 输出 111
```

```
变量\英文, A
变量\数字, 1
弹窗提示\@(@英文.@数字)      ; 输出 111（先算英文 -> "A"，再算数字 -> "1"，拼接为"A1"，再取值）
```

#### 3.2.3 变量未定义的处理

- 若引用的变量不存在，则 `@变量名` 会被当作字面字符串原样保留（但通常不会报错，只是返回空或原样）。
- 解析器会递归解析嵌套的 `@` 和 `@()`，确保最大灵活性。

### 3.3 数组操作

数组通过 `数组\创建` 等指令操作，详细参见第 6 节。


## 4. 条件表达式语法

### 4.0 核心规则：条件指令专用于 `如果`

以下指令**专门用于条件判断**，**不能**单独执行。它们必须紧跟在 `如果\` 后面作为条件子句：

| 指令 | 用途 | 是否可独立执行 |
|------|------|---------------|
| `识图` | 屏幕找模板 | **不能** |
| `识图CV` | 屏幕找图片（OpenCV） | **不能** |
| `坐标找色` | 检查单点颜色 | **不能** |
| `范围找色` | 区域找色 | **不能** |
| `比较` | 值比较 | **不能** |

 **错误示例**（会导致“未知指令”错误）：

```
识图CV\0,0,0,0,0.15,<logo.bmp>,中心X,中心Y\    ;  错误！不能独立执行
```

 **正确示例**：

```
如果\识图CV\0,0,0,0,0.15,<logo.bmp>,中心X,中心Y\
    弹窗提示\找到了
结束如果
```

### 4.1 基本格式

```
如果\条件类型\参数1,参数2,...\
    条件成立时执行的指令
    可以有多行
[否则如果\条件类型\参数1,参数2,...\]
    上一个条件不成立且此条件成立时执行
[否则\]
    所有条件都不成立时执行
结束如果
```

### 4.2 支持的条件类型

| 条件类型 | 参数格式 | 说明 |
|---------|---------|------|
| `识图` | `左上X,左上Y,右下X,右下Y,容错,<标记名>,结果变量,数量变量,X变量,Y变量,模式,超时秒数` | 模板匹配 |
| `识图CV` | `左上X,左上Y,右下X,右下Y,容错,<图片名>,X变量,Y变量` | OpenCV图片匹配 |
| `坐标找色` | `X,Y,颜色值,结果变量` | 单点颜色检测 |
| `范围找色` | `左,上,右,下,颜色值,容差,结果变量,X变量,Y变量` | 区域颜色搜索 |
| `比较` | `值1,操作符,值2,结果变量` | 值比较 |

各条件类型的参数详细说明见第 6 节。

### 4.3 逻辑连接词

- `\与\`：所有子条件都成立时整体为真（短路运算）。
- `\或\`：任一子条件成立时整体为真（短路运算）。

多个子条件可通过连接词串联，例如：

```
如果\识图\0,0,0,0,0.1,<头像>,找到,数量,X,Y\与\比较\@数量,大于,0,有头像\
    弹窗提示\头像已出现
结束如果
```

### 4.4 单一条件

若只有一个子条件，可直接使用，无需连接词。

```
如果\坐标找色\100,200,0xFF0000,颜色\
    弹窗提示\找到红色
结束如果
```

### 4.5 完整示例

```
如果\识图\0,0,0,0,0.1,<确认按钮>,结果ID,找到数量,X坐标,Y坐标\
    弹窗提示\找到 @找到数量 个确认按钮
    弹窗提示\第一个中心坐标：@X坐标, @Y坐标
    识图移动\0,0\
    鼠标\左键单击\
否则\
    弹窗提示\未找到确认按钮
结束如果
```


## 5. BNF 语法范式

### 5.1 基本符号

```
<脚本>           ::= { <行> }
<行>             ::= [<指令>] <换行>
<指令>           ::= <指令头> "\" [<参数段>]
<参数段>         ::= <参数> { "," <参数> }
<参数>           ::= <字面量> | <变量引用> | <标记> | <颜色值>
<变量引用>       ::= "@" <变量名> [ "[" <表达式> "]" ] | "@(" <拼接表达式> ")"
<拼接表达式>     ::= <片段> { "." <片段> }
<片段>           ::= <字面量> | <变量引用>
<标记>           ::= "<" <名称> ">"
<颜色值>         ::= "0x" <6位十六进制数>
<字面量>         ::= <数字> | <字符串> | <布尔值>
<换行>           ::= "\n"
<注释>           ::= ";" <任意字符>
```

### 5.2 单行指令

单行指令是指那些不产生块结构的指令，它们在一行内完成执行。

```
<单行指令>      ::= <指令头> "\" [<参数段>]
```

### 5.3 块结构

块结构由起始行、块体和结束行组成，支持嵌套。

#### 5.3.1 如果块

```
<如果块>        ::= "如果\" <条件表达式> <换行>
                     { <指令行> }
                     [ "否则如果\" <条件表达式> <换行> { <指令行> } ]
                     [ "否则\" <换行> { <指令行> } ]
                     "结束如果\" <换行>
```

- 多个 `否则如果` 可以连续出现。
- 条件表达式遵循第 4 节规则。
- 块体可以包含任意指令，包括嵌套的 `如果` 块。

#### 5.3.2 循环块

```
<循环块>        ::= "循环\" <次数表达式> [ "," <计数器变量> ] <换行>
                     { <指令行> }
                     "结束循环\" <换行>
```

- 次数可以是数字字面量或变量（`@变量名`）。
- 若次数为 `0`，表示无限循环。
- 计数器变量为可选，若提供，每次迭代会将当前循环次数（从 1 开始）存入该变量。

#### 5.3.3 模块定义块

```
<模块定义块>    ::= "模块定义\" <模块名> <换行>
                     { <指令行> }
                     "结束模块定义\" <换行>
```

- 模块名用于后续 `模块\模块名` 调用。
- 块体可包含任意指令（包括嵌套的块）。

### 5.4 条件表达式语法（用于“如果”）

```
<条件表达式>    ::= <子条件> { ( "\与\" | "\或\" ) <子条件> }
<子条件>        ::= <条件类型> "\" <参数段>
```

## 7. 模块与定时器系统

### 7.1 模块定义与调用

- 模块通过 `模块定义\模块名 ... 结束模块定义\` 定义，可出现在脚本任何位置（建议放在模块库页或脚本开头）。
- 模块内容会被存储，后续可通过 `模块\模块名` 调用执行。
- 模块支持嵌套调用（一个模块可调用另一个模块）。
- 模块内部可使用所有常规指令，包括循环、判断、变量等。

### 7.2 定时器（模块定时）

- `模块定时\模块名, 间隔毫秒, 模式` 用于启动或停止一个独立于主线程的定时器。
- **模式**：
  - `重复`：每隔指定毫秒执行一次模块，直到主线程结束或手动关闭。
  - `一次`：间隔后执行一次即自动失效。
  - `关闭`：立即停止该模块的定时器（间隔参数可填0）。
- 定时器与主流程并行，主线程的 `延迟` 或循环不会阻塞定时器触发。
- 主线程执行完毕或手动停止脚本时，所有定时器自动销毁。
- 定时器内部建议避免耗时操作，以免影响触发精度。


## 8. 错误处理与终止规则

### 8.1 语法错误

- 指令头未知：脚本停止执行，并提示“未知指令”。
- 参数数量不足：部分指令会抛出错误并终止。
- 块未闭合：若 `如果`、`循环`、`模块定义` 未找到匹配的结束关键字，脚本停止并提示缺少结束标记。

### 8.2 运行时错误

- 除零错误：`运算\除` 或 `取余` 除数为0时，脚本停止。
- 数组索引越界：访问数组超出范围时，返回空值（不停止）。
- 变量未定义：引用不存在的变量时，返回值可能为空或原样保留（不停止）。
- 文件操作失败（如打开Excel文件失败）：脚本停止并提示错误。

### 8.3 异常中断

- 用户可通过外部快捷键（如`F3`）请求停止脚本，脚本在执行完当前指令后检查退出标志并终止。
- 脚本执行期间遇到致命错误（如内存不足）时，会触发清理流程并退出。

### 8.4 清理机制

脚本结束（正常或异常）时，会执行以下清理：
- 停止所有定时器。
- 关闭所有打开的Excel进程（如果未保存，可能丢失修改）。
- 释放后台绑定和硬件驱动资源。
- 清空全局变量和缓存。
