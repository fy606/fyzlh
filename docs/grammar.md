# 🍁 枫叶指令宏

🚀 **枫叶指令宏——让自动化变得简单！无需编程基础，通过简单指令即可实现自动化操作。**

---

## 第一部分：核心语法规范

---

### 1.1 指令分类

枫叶语言中的指令分为两类：

| 指令类型     | 说明                                    | 示例                                               |
| ------------ | --------------------------------------- | -------------------------------------------------- |
| **执行指令** | 可独立执行，完成具体操作                | `变量\等级,10`、`鼠标移动\100,200`、`延迟\500,800` |
| **条件指令** | **只能**用于 `如果\` 后面，不能独立执行 | `识图\...`、`坐标找色\...`、`比较\...`             |

⚠️ **重要**：条件指令（`识图`、`识图CV`、`坐标找色`、`范围找色`、`比较`）**不能单独写在一行**，必须紧跟在 `如果\` 后面作为条件子句。否则解析器会报告"未知指令"错误。

---

### 1.2 注释规则

- 以英文分号 `;` 开头的行均为注释，执行时完全忽略。
- 注释必须独占一行。

```
; 这是一条注释，运行时不会运行这一条
变量\等级,10
```

---

### 1.3 分隔符规则

- **指令分隔符**：指令与参数之间用反斜杠 `\` 分隔。即使没有参数，指令末尾也必须保留 `\`。

```
按键\a\
鼠标\左键单击\
延迟\500,1000\
```

- **参数分隔符**：多个参数之间用英文逗号 `,` 分隔。

```
鼠标移动\777,574\
变量\等级,10\
```

---

### 1.4 变量调用规则

- 使用 `@变量名` 的形式引用已定义的变量值。
- 定义变量时**不加** `@`，引用变量时**必须加** `@`。

```
变量\超时,0\          ; 定义变量（不加 @）
弹窗提示\@超时\        ; 引用变量（加 @）
```

- **数组索引访问**：通过 `@变量名[索引]` 访问数组元素，**索引从 1 开始**。

```
数组\创建,英雄列表, 亚瑟|后羿|妲己
弹窗提示\第一个英雄是 @英雄列表[1]
```

- **拼接表达式**：使用 `@(拼接内容)` 动态拼接变量名，拼接符为 `.`。

```
变量\A1, 111
变量\数字, 1
弹窗提示\@(A.@数字)          ; 输出 111
```

- **变量未定义**：若引用的变量不存在，则返回空值。

---

### 1.5 块结构规则

块结构通过**起始关键字**与**结束关键字**配对实现，支持嵌套。

| 块类型 | 起始关键字  | 结束关键字      | 说明                                            |
| ------ | ----------- | --------------- | ----------------------------------------------- |
| 判断块 | `如果\`     | `结束如果\`     | 条件判断，支持 `否则如果\`、`否则`              |
| 循环块 | `循环\`     | `结束循环\`     | 重复执行，支持 `终止本层循环\`、`跳过本次循环\` |
| 模块块 | `模块定义\` | `结束模块定义\` | 定义可复用的代码模块                            |

- 块结构**必须配对**，缺少结束关键字将触发语法错误。
- 块体内部可包含任意指令（包括嵌套的块）。
- **禁止使用 `{}` 或缩进来表示块范围**，必须使用配对关键字。

```
如果\条件\
    条件成立时执行的指令
否则如果\条件2\
    条件2成立时执行的指令
否则\
    所有条件都不成立时执行
结束如果
```

---

### 1.6 循环结构体

循环结构体用于重复执行一段指令序列。**循环结构体支持嵌套**（即循环体内可再包含循环）。

- **结构**：
```
循环\次数[, 计数器变量]\
    ...             ; 循环体内的指令
结束循环\
```

- **次数说明**：次数为 `0` 表示无限循环；次数支持变量引用，如 `循环\@总人数\`。
- **计数器变量（可选）**：`循环\次数,计数器变量名\`，每次迭代将当前次数（从 1 开始）存入该变量。

- **循环控制指令**（必须独立成行）：
  - `终止本层循环\`：立即退出当前最内层循环
  - `跳过本次循环\`：跳过当前迭代，进入下一次迭代

- **简单示例**：
```
; 左键连点10下
循环\10, 循环次数\
    鼠标\左键单击\
结束循环\
```

- **无限循环 + 条件退出**：
```
变量\计数,0\
循环\0, 循环次数\
    悬浮提示\@计数,0,0,1\
    如果\比较\@计数,大于等于,10,结果\
        终止本层循环\
    否则\
        运算\@计数,加,1,计数\
    结束如果
    延迟\1000,1000\
结束循环\
```

---

### 1.7 模块结构体

模块结构体用于封装一段可复用的指令序列，实现代码的模块化。

- **结构**：
```
模块定义\模块名\
    ...                 ; 模块内的指令（可包含任意指令）
结束模块定义\
```

- **特性**：
  - 模块内可以调用其他模块，但需注意避免递归调用导致死循环。
  - 模块内可包含循环、判断等任何结构体，但**不能再定义新模块**（模块定义不可嵌套）。
  - 模块调用会同步执行，即调用后等待模块执行完毕才继续后续指令。

- **调用格式**：
```
模块\模块名\            ; 执行已定义的模块
```

- **定时调用格式**：
```
模块定时\模块名,毫秒,模式\      ; 模式：重复、一次、关闭
```

- **简单示例**：
```
模块定义\登录游戏\
    鼠标移动\500,300\
    鼠标\左键单击\
    延迟\1000,1000\
    按键\Enter\
结束模块定义\

模块\登录游戏\       ; 调用模块
```

- **嵌套调用示例**：
```
模块定义\模块B\
    弹窗提示\模块B 被调用\
结束模块定义\

模块定义\模块A\
    弹窗提示\模块A 开始执行\
    模块\模块B\               ; 调用模块 B
    弹窗提示\模块A 执行结束\
结束模块定义\

模块\模块A\          ; 主程序调用模块 A
```

- **定时调用示例**：
```
模块定义\提醒\
    弹窗提示\时间到！\
结束模块定义\

模块定时\提醒,5000,一次\   ; 5秒后弹窗
延迟\10000,10000\          ; 主线程继续执行
```

### 1.8 条件判断结构

- 以 `如果\` 开头，后跟一个或多个条件指令。
- 条件指令之间可通过 `\与\` 或 `\或\` 连接。
- 使用 `否则如果\`、`否则` 处理多分支逻辑。
- 必须以 `结束如果\` 结尾。

```
如果\比较\@血量,小于,30,低血量\
    弹窗提示\血量过低！
否则如果\比较\@血量,小于,60,中血量\
    弹窗提示\血量中等
否则\
    弹窗提示\血量安全
结束如果
```

- **支持的条件指令**：

| 条件指令   | 用途           | 示例                                              |
| ---------- | -------------- | ------------------------------------------------- |
| `比较`     | 值比较         | `如果\比较\@分数,大于等于,60,是否及格\`           |
| `坐标找色` | 检查单点颜色   | `如果\坐标找色\100,200,0xFF0000,色值\`            |
| `范围找色` | 区域找色       | `如果\范围找色\0,0,100,100,0xFFFFFF,10,结果,X,Y\` |
| `识图`     | 模板匹配       | `如果\识图\0,0,0,0,0.1,<头像>,id,count,x,y\`      |
| `识图CV`   | OpenCV图片匹配 | `如果\识图CV\0,0,0,0,0.15,<logo.bmp>,X,Y\`        |

- **识图模式说明**：
  - `等待出现`：等待模板出现，超时后失败
  - `等待消失`：等待模板消失，超时后失败
  - 省略模式：执行一次，立即返回结果（不等待）

---

### 1.9 BNF 基本范式

```
<脚本>           ::= { <行> }
<行>             ::= [<指令>] <换行>
<指令>           ::= <指令头> "\" [<参数段>]
<参数段>         ::= <参数> { "," <参数> }
<参数>           ::= <字面量> | <变量引用> | <标记> | <颜色值>
<变量引用>       ::= "@" <变量名> [ "[" <表达式> "]" ] | "@(" <拼接表达式> ")"
<拼接表达式>     ::= <片段> { "." <片段> }
<标记>           ::= "<" <名称> ">"
<颜色值>         ::= "0x" <6位十六进制数>
<字面量>         ::= <数字> | <字符串> | <布尔值>
<换行>           ::= "\n"
<注释>           ::= ";" <任意字符>
```

## 第二部分：功能指令详细参数

---

### 2.1 辅助指令

---

#### 文本输入（执行指令）

- **格式**：`文本输入\输入内容\`
- **功能**：模拟键盘输入指定文本到当前激活的窗口，支持变量引用。
- **参数**：输入内容【必填】支持纯文本、字符串变量（`@变量名`）
- **示例**：
```
文本输入\枫叶指令宏\
文本输入\当前用户：@用户名\
```

---

#### 文本播报（执行指令）

- **格式**：`文本播报\播报文本,等待模式,语速,音量\`
- **功能**：调用系统语音引擎进行语音播报。
- **参数**：
  1. 播报文本：【必填】支持变量引用
  2. 等待模式：【必填】`等待`、`不等待`
  3. 语速：【必填】整数 -10 ~ 10
  4. 音量：【必填】整数 0 ~ 100
- **示例**：
```
文本播报\枫叶指令宏,等待,5,80\
文本播报\当前计数为@计数,不等待,0,100\
```

---

#### 运算（执行指令）

- **格式**：`运算\数值1,运算符,数值2,结果变量名\`
- **功能**：算术运算，结果存入变量。
- **运算符**：`加`、`减`、`乘`、`除`、`取余`
- **示例**：
```
运算\3,加,4,运算结果\
运算\@超时,加,1,超时\
运算\10,乘,@倍率,最终值\
```

---

#### 随机数（执行指令）

- **格式**：`随机数\最小值,最大值,结果变量名\`
- **功能**：生成指定范围随机整数。
- **示例**：
```
随机数\100,200,随机值\
随机数\@最小随机,@最大随机,随机延迟\
```

---

#### 文字识别（执行指令）

- **格式**：`文字识别\X1,Y1,X2,Y2,容错率,<字库数据名>,识别结果变量\`
- **功能**：基于字库识别屏幕文字。
- **示例**：
```
文字识别\0,0,116,41,0.1,<主字库>,识别结果\
弹窗提示\@识别结果\
```

---

#### 大模型文字识别（执行指令）

- **格式**：`大模型文字识别\X1,Y1,X2,Y2,识别结果变量,字段数量变量,坐标X变量,坐标Y变量\`
- **功能**：调用大模型OCR识别屏幕文字。
- **补充说明**：每个字段的坐标自动存入 `坐标X变量1`、`坐标Y变量1`、`坐标X变量2`、`坐标Y变量2`……
- **示例**：
```
大模型文字识别\0,0,116,41,识别结果,字段数量,文字X,文字Y\
弹窗提示\@识别结果\
```

### 2.2 基本功能

---

#### 弹窗提示（执行指令）

- **格式**：`弹窗提示\提示内容\`
- **功能**：弹出消息框（阻塞执行）。
- **示例**：
```
弹窗提示\操作完成\
弹窗提示\当前血量：@血量，蓝量：@蓝量\
```

---

#### 悬浮提示（执行指令）

- **格式**：`悬浮提示\提示文本,X坐标,Y坐标,提示编号\`
- **功能**：显示悬浮提示，编号1~20独立。
- **示例**：
```
悬浮提示\脚本运行中,0,0,1\
悬浮提示\当前计数：@计数,100,0,2\
```

---

#### 运行程序（执行指令）

- **格式**：`运行程序\目标地址\`
- **路径规则**：必须使用正斜杠 `/`
- **示例**：
```
运行程序\notepad.exe\
运行程序\https://www.baidu.com/\
运行程序\D:/测试文件.txt\
```

---

#### 关闭程序（执行指令）

- **格式**：`关闭程序\进程名\`
- **示例**：
```
关闭程序\微信.exe\
关闭程序\notepad.exe\
```

---

#### 坐标提示（执行指令）

- **格式**：`坐标提示\X坐标,Y坐标\`
- **功能**：在指定位置显示标记提示。
- **示例**：
```
坐标提示\@识图X,@识图Y\
坐标提示\777,574\
```

### 2.3 高级功能

---

#### 开启后台（执行指令）

- **格式**：`开启后台\窗口名,后台模式\`
- **模式**：`1`、`1+`、`2`、`2+`、`3`
- **示例**：
```
开启后台\QQ,1\
```
- **注意**：窗口不能最小化，黑屏时尝试更换模式。

---

#### 关闭后台（执行指令）

- **格式**：`关闭后台\`
- **参数**：无
- **示例**：
```
关闭后台\
```

---

#### 获取鼠标（执行指令）

- **格式**：`获取鼠标\X坐标变量,Y坐标变量\`
- **示例**：
```
获取鼠标\当前X,当前Y\
弹窗提示\@当前X,@当前Y\
```

---

#### 获取时间（执行指令）

- **格式**：`获取时间\年变量,月变量,日变量,时变量,分变量,秒变量\`
- **示例**：
```
获取时间\年,月,日,时,分,秒\
弹窗提示\@年-@月-@日 @时:@分:@秒\
```

---

#### 关机操作（执行指令）

- **格式**：`关机操作\关机类型\`
- **类型**：`正常关机`、`强制关机`
- **示例**：
```
关机操作\正常关机\
关机操作\强制关机\
```

---

#### 抓图（执行指令）

- **格式**：`抓图\X1,Y1,X2,Y2,数据名,处理模式,阈值\`
- **模式**：`灰度阈值`、`灰度差值`
- **示例**：
```
抓图\0,0,100,100,开始按钮,灰度阈值,150\
```

---

#### 截图（执行指令）

- **格式**：`截图\X1,Y1,X2,Y2,截图文件名\`
- **全屏**：`0,0,0,0`
- **示例**：
```
截图\0,0,0,0,全屏截图\
截图\100,100,200,200,区域截图\
截图\0,0,0,0,第@次数张\      ; 支持变量拼接
```

### 2.4 字符功能

---

#### 字符串长度（执行指令）

- **格式**：`字符串长度\源字符串,长度结果变量\`
- **示例**：
```
字符串长度\@识别结果,长度结果\
弹窗提示\@长度结果\
```

---

#### 坐标提取（执行指令）

- **格式**：`坐标提取\源字符串,坐标X变量,坐标Y变量\`
- **支持格式**：`X:100 Y:200`、`100,200`、`(100,200)`、`【100，200】`
- **示例**：
```
坐标提取\@坐标文本,目标X,目标Y\
鼠标移动\@目标X,@目标Y\
```

---

#### 检索字符串（执行指令）

- **格式**：`检索字符串\源字符串,字符位置,结果变量\`
- **位置从 1 开始**
- **示例**：
```
检索字符串\@识别结果,1,首字符\
弹窗提示\@首字符\
```

---

#### 提取字符（执行指令）

- **格式**：`提取字符\源字符串,提取规则,结果变量名\`
- **规则**：`英文字母`、`大写字母`、`小写字母`、`中文字符`、`数字字符`
- **示例**：
```
提取字符\abc123中文,英文字母,提取结果\   ; 提取结果="abc"
提取字符\手机号138-0013-8000,数字字符,手机号\  ; 手机号="13800138000"
```

### 2.6 表格操作

表格指令统一使用 `表格\子命令,参数...` 格式。

| 子命令   | 格式                                                               | 说明            |
| -------- | ------------------------------------------------------------------ | --------------- |
| `新建`   | `表格\新建, 文件路径\`                                             | 创建新Excel文件 |
| `打开`   | `表格\打开, 文件路径, 上下文变量名\`                               | 打开Excel文件   |
| `读单格` | `表格\读单格, 上下文变量, 工作表, 单元格引用, 结果变量\`           | 读取单个单元格  |
| `写单格` | `表格\写单格, 上下文变量, 工作表, 单元格引用, 写入内容\`           | 写入单个单元格  |
| `保存`   | `表格\保存, 上下文变量\`                                           | 保存文件        |
| `读行`   | `表格\读行, 上下文变量, 工作表, 起始引用, 结果变量列表\`           | 向右读取一行    |
| `读列`   | `表格\读列, 上下文变量, 工作表, 起始引用, 结果变量列表\`           | 向下读取一列    |
| `写行`   | `表格\写行, 上下文变量, 工作表, 起始引用, 写入内容列表或数组变量\` | 向右写入一行    |
| `写列`   | `表格\写列, 上下文变量, 工作表, 起始引用, 写入内容列表或数组变量\` | 向下写入一列    |
| `读公式` | `表格\读公式, 上下文变量, 工作表, 单元格引用, 结果变量\`           | 读取公式文本    |
| `写公式` | `表格\写公式, 上下文变量, 工作表, 单元格引用, 公式字符串\`         | 写入公式        |

**单元格引用**：支持 A1 格式（如 `A1`）或数字格式（如 `1 1`，列和行用空格隔开）

**示例**：
```
表格\新建, C:/Users/Desktop/新建工作簿.xlsx\
表格\打开, C:/Users/Desktop/新建工作簿.xlsx, 表格数据\
表格\读单格, 表格数据, 1, A1, 单格结果\
表格\写单格, 表格数据, 1, 1 1, 100\
表格\保存, 表格数据\
表格\读行, 表格数据, 1, 2 1, 行1|行2|行3\
表格\写行, 表格数据, 1, 2 1, 行结果1|行结果2|行结果3\
表格\读公式, 表格数据, 1, C1, 公式结果\
表格\写公式, 表格数据, 1, D1, =SUM(A1:C1)\
```

## 附录 B：错误码速查

| 错误描述              | 可能原因                                     |
| --------------------- | -------------------------------------------- |
| `未知指令: xxx`       | 指令头不在关键字清单中；或条件指令被独立执行 |
| `缺少 '结束如果'`     | `如果` 块未闭合                              |
| `缺少 '结束循环'`     | `循环` 块未闭合                              |
| `缺少 '结束模块定义'` | `模块定义` 块未闭合                          |
| `参数不足`            | 指令参数数量不满足                           |
| `除数不能为零`        | `运算\除` 或 `取余` 除数为0                  |
| `数组不存在`          | 操作的数组未创建                             |
| `索引超出范围`        | 数组索引小于1或大于长度                      |
| `识图数据未找到`      | 抓图数据不存在或标记名错误                   |
| `图像文件不存在`      | 图片文件不在 ScreenShot 目录                 |
