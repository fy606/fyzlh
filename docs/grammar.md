
# 🍁枫叶指令宏

🚀 **枫叶指令宏——让自动化变得简单！无需编程基础，通过简单指令即可实现自动化操作。**

---

### 1. 📝 核心语法规范

---

#### 1.1 指令分类

枫叶语言中的指令分为两类：

| 指令类型     | 说明                                    | 示例                                               |
| ------------ | --------------------------------------- | -------------------------------------------------- |
| **执行指令** | 可独立执行，完成具体操作                | `变量\等级,10`、`鼠标移动\100,200`、`延迟\500,800` |
| **条件指令** | **只能**用于 `如果\` 后面，不能独立执行 | `识图\...`、`坐标找色\...`、`比较\...`             |

⚠️ **重要**：条件指令（`识图`、`识图CV`、`坐标找色`、`范围找色`、`比较`）**不能单独写在一行**，必须紧跟在 `如果\` 后面作为条件子句。否则解析器会报告“未知指令”错误。

---

#### 1.2 注释规则

- 以英文分号 `;` 开头的行均为注释，执行时完全忽略。
- 注释必须独占一行，不可写在指令同行末尾（行内注释将被丢弃）。

```
; 这是一条注释，运行时不会运行这一条
变量\等级,10   ; 这是行内注释（`;` 之后的内容全部丢弃）
```

---

#### 1.3 分隔符规则

- **指令分隔符**：指令与参数之间用反斜杠 `\` 分隔。即使没有参数，指令末尾也必须保留 `\`。

```
按键\a\
鼠标\左键单击\
延迟\500,1000\
```

- **参数分隔符**：多个参数之间用英文逗号 `,` 分隔。

```
鼠标移动\777,574\
变量\等级,10\
```

---

#### 1.4 变量调用规则

- 使用 `@变量名` 的形式引用已定义的变量值。
- 定义变量时**不加** `@`，引用变量时**必须加** `@`。

```
变量\超时,0\          ; 定义变量（不加 @）
弹窗提示\@超时\        ; 引用变量（加 @）
```

- **数组索引访问**：通过 `@变量名[索引]` 访问数组元素，**索引从 1 开始**。

```
数组\创建,英雄列表, 亚瑟|后羿|妲己
弹窗提示\第一个英雄是 @英雄列表[1]
```

- **拼接表达式**：使用 `@(拼接内容)` 动态拼接变量名，拼接符为 `.`。

```
变量\A1, 111
变量\数字, 1
弹窗提示\@(A.@数字)          ; 输出 111
```

- **变量未定义**：若引用的变量不存在，则返回空值。

---

#### 1.5 块结构规则

块结构通过**起始关键字**与**结束关键字**配对实现，支持嵌套。

| 块类型 | 起始关键字  | 结束关键字      | 说明                                            |
| ------ | ----------- | --------------- | ----------------------------------------------- |
| 判断块 | `如果\`     | `结束如果\`     | 条件判断，支持 `否则如果\`、`否则\`             |
| 循环块 | `循环\`     | `结束循环\`     | 重复执行，支持 `终止本层循环\`、`跳过本次循环\` |
| 模块块 | `模块定义\` | `结束模块定义\` | 定义可复用的代码模块                            |

- 块结构**必须配对**，缺少结束关键字将触发语法错误。
- 块体内部可包含任意指令（包括嵌套的块）。
- **禁止使用 `{}` 或缩进来表示块范围**，必须使用配对关键字。

```
如果\条件\
    条件成立时执行的指令
否则如果\条件2\
    条件2成立时执行的指令
否则\
    所有条件都不成立时执行
结束如果
```

---

#### 1.6 循环控制指令

在循环体内可使用以下控制指令（**必须独立成行**）：

| 指令            | 说明                         |
| --------------- | ---------------------------- |
| `终止本层循环\` | 立即退出当前最内层循环       |
| `跳过本次循环\` | 跳过当前迭代，进入下一次迭代 |

```
循环\10\
    如果\比较\@计数,大于等于,10,结果\
        成功\终止本层循环\     ; 独立成行
        失败\跳过本次循环\     ; 独立成行
    结束如果
结束循环
```

---

#### 1.7 条件判断结构

- 以 `如果\` 开头，后跟一个或多个条件指令。
- 条件指令之间可通过 `\与\` 或 `\或\` 连接。
- 使用 `否则如果\`、`否则\` 处理多分支逻辑。
- 必须以 `结束如果\` 结尾。

```
如果\比较\@血量,小于,30,低血量\
    弹窗提示\血量过低！
否则如果\比较\@血量,小于,60,中血量\
    弹窗提示\血量中等
否则\
    弹窗提示\血量安全
结束如果
```

#### 1.8 BNF 基本范式

```
<脚本>           ::= { <行> }
<行>             ::= [<指令>] <换行>
<指令>           ::= <指令头> "\" [<参数段>]
<参数段>         ::= <参数> { "," <参数> }
<参数>           ::= <字面量> | <变量引用> | <标记> | <颜色值>
<变量引用>       ::= "@" <变量名> [ "[" <表达式> "]" ] | "@(" <拼接表达式> ")"
<拼接表达式>     ::= <片段> { "." <片段> }
<标记>           ::= "<" <名称> ">"
<颜色值>         ::= "0x" <6位十六进制数>
<注释>           ::= ";" <任意字符>
```

#### 1.10 AI编写规范速查表

| 规则                     | 正确示例                                     | 错误示例                                |
| ------------------------ | -------------------------------------------- | --------------------------------------- |
| 条件指令必须在 `如果` 后 | `如果\识图\0,0,0,0,0.1,<头像>,id,count,x,y\` | `识图\0,0,0,0,0.1,<头像>,id,count,x,y\` |
| 尾部可选参数直接省略     | `识图\0,0,0,0,0.1,<头像>,id,count,x,y\`      | `识图\...,无,0\`                        |
| 块结构使用配对关键字     | `如果\...\结束如果\`                         | `如果\...{...}`                         |
| 变量引用加 `@`           | `@变量名`                                    | `变量名`                                |
| 参数用逗号分隔           | `变量\等级,10`                               | `变量\等级 10`                          |
| 块内不用缩进（但允许）   | 顶格书写                                     | 强制缩进（无实际作用）                  |
