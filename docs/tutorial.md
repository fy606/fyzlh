# 🍁枫叶指令宏

🚀 **枫叶指令宏——让自动化变得简单！无需编程基础，通过简单指令即可实现自动化操作。**

---

## 1. 🚀 快速上手教程

---

### 1.1 第一个脚本：自动打开记事本并输入文字

- **目标**：自动启动 Windows 记事本，等待窗口打开，然后输入文字 “Hello World”。

- **核心指令**：
  - `运行程序\`：启动程序
  - `延迟\`：等待窗口加载
  - `激活窗口\`：将窗口置前
  - `文本输入\`：模拟文本输入

- **完整脚本**：

```
; 第一个脚本：自动打开记事本并输入 Hello World
运行程序\notepad.exe\
延迟\1000,1500\          ; 等待记事本启动
激活窗口\记事本\          ; 激活记事本窗口
延迟\500,500\            ; 确保窗口完全激活
文本输入\Hello World\    ; 输入文本
```

![tutorial_1.gif](https://raw.gitcode.com/user-images/assets/9413885/889001eb-cfd6-4640-ac8b-f21e95f8f081/tutorial_1.gif 'tutorial_1.gif')

- **执行说明**：
  - 如果记事本启动较慢，可以适当增加延迟范围。
  - `激活窗口\` 支持模糊匹配窗口标题（包含“记事本”即可）。

### 1.2 第二个脚本：定时检测窗口并弹窗提醒

- **目标**：每 5 秒检测一次“微信”窗口是否存在，如果存在则弹出提示并停止检测。

- **核心指令**：
  - `模块定义\...结束模块定义\`：定义可复用模块
  - `模块定时\`：启动定时器（独立于主线程）
  - `判断窗口\`：检测窗口状态
  - `如果\...否则\...结束如果\`：条件判断

- **完整脚本**：

```
; 定义检测模块
模块定义\窗口检测\
    判断窗口\微信,存在,窗口存在结果\
    如果\比较\@窗口存在结果,等于,1,存在\
        弹窗提示\微信已运行！\
        模块定时\窗口检测,0,关闭\   ; 关闭定时器，避免重复弹窗
    否则\
        悬浮提示\未检测到微信,100,100,1\
    结束如果
结束模块定义\

; 启动定时检测，每5秒执行一次
模块定时\窗口检测,5000,重复\

; 主线程保持运行（例如持续10秒）
延迟\10000,10000\
; 10秒后主线程结束，定时模块自动清除
```

- **执行说明**：
  - `判断窗口\` 的第二个参数是 `存在`；也可改为 `激活` 检测窗口是否处于激活状态。
  - 定时模块独立于主线程运行，主线程结束时所有定时任务自动终止。
  - 弹窗后关闭定时器，避免重复弹窗。

### 1.3 第三个脚本：图像识别并点击关闭按钮

- **目标**：在屏幕指定区域查找“关闭”按钮图像（如广告弹窗的 X 按钮），找到后点击它。

- **前提**：已使用 `抓图` 工具截取关闭按钮图像并命名为 `<X按钮>`。

- **核心指令**：
  - `循环\`：循环等待
  - `如果\识图\...等待出现,超时\`：等待图像出现
  - `识图移动\`：移动到识别位置
  - `鼠标\左键单击\`：点击
  - `终止本层循环\`：退出循环

- **完整脚本**：

```
; 定义搜索区域（假设广告弹窗通常出现在屏幕中央）
变量\区域左,600\
变量\区域上,400\
变量\区域右,800\
变量\区域下,600\

; 循环等待关闭按钮出现
循环\0, 循环次数\
    如果\识图\@区域左,@区域上,@区域右,@区域下,0.1,<X按钮>,标记,数量,X,Y,等待出现,10\
        识图移动\0,0\
        鼠标\左键单击\
        延迟\500,500\
        终止本层循环\        ; 点击后退出循环
    否则\
        延迟\1000,1000\      ; 没找到则等待1秒后继续查找
    结束如果
结束循环\

; 点击完成
悬浮提示\广告已关闭,0,0,1\
弹窗提示\广告已关闭\
```

- **执行说明**：
  - `识图\` 使用 `等待出现` 模式，最多等待 10 秒。
  - `识图移动\` 会自动使用上一次识别到的坐标（X、Y）并加上偏移量（此处为 0,0）。
  - 找到并点击后，用 `终止本层循环\` 退出无限循环。

### 1.4 第四个脚本：鼠标移动至两张图片中心点

- **目标**：同时找到图像 a 和图像 b，计算两者 X 轴方向的中间位置，将鼠标移动到该点。

- **前提**：已使用 `抓图` 工具截取两个目标图像，并命名为 `<a>` 和 `<b>`。

- **核心指令**：
  - `如果\识图\...\与\识图\...\`：多条件组合（与逻辑）
  - `运算\`：计算距离和中间值
  - `鼠标移动\`：移动到计算后的坐标

- **完整脚本**：

```
; 同时识别图像 a 和 b，计算中点并移动鼠标
如果\识图\0,0,0,0,0.1,<a>,标记结果,数量,X1,Y1\与\识图\0,0,0,0,0.1,<b>,标记结果,数量,X2,Y2\
    运算\@X2,减,@X1,距离\
    运算\@距离,除,2,半距\
    运算\@X1,加,@半距,中间X\
    鼠标移动\@中间X,@Y1\
否则\
    弹窗提示\未找到目标图片 a 或 b\
结束如果
```

- **执行说明**：
  - `\与\` 连接两个 `识图` 条件，只有两个都找到时才执行成功分支。
  - `识图` 返回第一个匹配点的坐标（X1、Y1、X2、Y2）。
  - 计算 `中间X = X1 + (X2 - X1) / 2`，Y 轴沿用图像 a 的 Y 坐标。
  - 如果任一图像未找到，执行 `否则\` 分支提示错误。

## 2. 💡 进阶技巧与最佳实践

---

### 2.1 脚本调试技巧

#### 利用弹窗/悬浮提示输出变量

- `弹窗提示\` 会阻塞脚本，适合查看关键节点的变量值。
- `悬浮提示\` 不阻塞，适合持续监控变量变化（可指定不同编号同时显示多个值）。

**示例：输出循环计数**

```
变量\计数,0\
循环\10, 循环次数\
    运算\@计数,加,1,计数\
    悬浮提示\当前计数：@计数,100,100,1\
    延迟\500,500\
结束循环\
```

#### 断点思路

- 在疑似问题位置前插入 `弹窗提示\暂停检查\`，脚本执行到此会暂停，点击确定后继续。
- 结合 `获取鼠标\`、`获取时间\` 等指令输出当前环境信息。

```
获取鼠标\当前X,当前Y\
弹窗提示\当前鼠标位置：@当前X, @当前Y\
```

#### 日志记录

- 可通过软件日志面板查看执行记录。
- 错误日志可定位问题行。

---

### 2.2 错误处理与容错设计

#### 利用 `否则\` 分支实现重试机制

- 在可能失败的操作（如识图、找色）后，通过循环和计数实现有限次重试。

**示例：识图点击重试最多 3 次**

```
变量\重试次数,0\
循环\0, 循环次数\
    如果\比较\@重试次数,大于等于,3,超时\
        弹窗提示\重试超时，退出\
        终止本层循环\
    否则\
        如果\识图\0,0,1000,800,0.1,<button>,标记,数量,x,y\
            识图移动\0,0\
            鼠标\左键单击\
            终止本层循环\
        否则\
            运算\@重试次数,加,1,重试次数\
            延迟\1000,1000\
        结束如果\
    结束如果\
结束循环\
```

#### 超时退出设计

- 在循环开始前记录起始时间，循环内判断是否超时。

```
; 记录开始时间（转换为总秒数）
获取时间\年,月,日,时,分,秒\
变量\开始秒,0\
运算\@时,乘,3600,开始秒\
运算\@开始秒,加,@分,乘60,开始秒\
运算\@开始秒,加,@秒,开始秒\

循环\0, 循环次数\
    ; 获取当前时间
    获取时间\年,月,日,时,分,秒\
    变量\当前秒,0\
    运算\@时,乘,3600,当前秒\
    运算\@当前秒,加,@分,乘60,当前秒\
    运算\@当前秒,加,@秒,当前秒\
    运算\@当前秒,减,@开始秒,耗时\

    如果\比较\@耗时,大于,30,超时\
        弹窗提示\操作超时\
        终止本层循环\
    否则\
        ; 正常操作（例如识图、鼠标点击等）
        延迟\500,500\
    结束如果
结束循环\
```

## 附录：核心语法速查

| 类别     | 说明                  | 示例                                     |
| -------- | --------------------- | ---------------------------------------- |
| 执行指令 | 可独立执行            | `变量\等级,10`、`鼠标移动\100,200`       |
| 条件指令 | 必须跟在 `如果\` 后面 | `如果\比较\@等级,大于,5,结果\`           |
| 块结构   | 配对关键字            | `如果\...结束如果\`、`循环\...结束循环\` |
| 变量引用 | 加 `@` 前缀           | `@变量名`、`@数组[1]`                    |
| 数组元素 | 用 `\|` 分隔          | `亚瑟\|后羿\|妲己`                       |
| 文件路径 | 使用正斜杠 `/`        | `C:/Users/Desktop/文件.txt`              |
